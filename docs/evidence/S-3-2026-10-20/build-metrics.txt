## 3. 关键结论（可复核）

```
· ENABLED=0 的 bss = 1224221 = 上一版生产的 bss ⇒ 宏关闭时采样器**零静态 RAM**（不是"留着数组只关逻辑"）
· loop_stats.cpp.o: enabled  text=1736 data=8 bss=586;  disabled text=875 data=0 bss=0
· 因此"新增静态 RAM"= bss +584 B（ELF 口径）/ bss 586 B（目标文件口径），取 ELF 口径为准
· .data 差值（+1464 B）主要是 syscmd_loop 的 JSON 键名与原因字符串（.rodata，落 Flash/DROM），
  其不计入 PlatformIO 的 RAM 数字（后者只算 DRAM 段）
```
