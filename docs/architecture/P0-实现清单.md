## P0-1 DeviceIdentity 模块

| 字段 | 内容 |
|---|---|
| **编号** | **P0-1** |
| **目标** | 提供**唯一的设备身份来源** `device_id`，并使其成为**运行期身份锚点**（NVS namespace `gfid`）；首启生成、后续以锚点为准、NVS 丢失时**有条件重建** |
| **修改文件** | **新增**：`src/services/device_identity.h` · `src/services/device_identity.cpp`（**仅身份**）<br>**改**：`src/main.cpp`（+1 行；**模板渲染不在本包**，见 P0-2） |
| **修改函数** | 新增：`void device_identity_init()` · `const char* device_id()` · `bool device_id_valid()`（**仅此 3 个**；`device_identity_reset()` **v1.2 已删除** —— 身份重置 ≠ factory reset，防误调用致身份漂移；模板渲染见 P0-2）<br>已有：`setup()`（`src/main.cpp:436`，`:517` 之后插入 `device_identity_init();`） |
| **修改内容** | 1. `esp_read_mac(mac, ESP_MAC_WIFI_STA)` 读 eFuse MAC（**固定 WIFI_STA**、**纯 eFuse 路径**、不依赖 Wi-Fi）<br>2. `snprintf("%02x"×6)` ⇒ 12 位小写 hex<br>3. NVS：`Preferences`，namespace `gfid`；key `did` = **ASCII 字符串 / 长度 12 个字符 / 内容为小写 hex**（**禁止写 "12 bytes"**）· key `dver` = `uint8` 算法版本号（= `1`）<br>4. **启动决策表 4 条路径**：无 `did` → 派生并写入（打印 `new device_id=`）；`did` 一致 → 使用（`device_id=`）；`did` 不一致 → **以 NVS 为准 + WARN `mac mismatch, keep nvs id`**（**不覆盖**）；**未知 `dver`** → **保留 `did` + WARN**（**不重算、不覆盖、不阻断启动**）<br>5. 状态用**文件作用域 static**：`s_device_id[13]` / `s_dver` / `s_ready` —— **零裸全局、不进 System State**<br>6. **（v1.2 移出）** 模板宏**不属于本模块** ⇒ 单点定义在 `topic_renderer.h`（P0-2）<br>7. 启动打印一行 `[Identity] ...`（可观测性的唯一手段）<br>8. NVS 写入失败 ⇒ **保留内存派生值 + 串口 WARN（一次）**，不重启 / 不重试 / 不置 State |
| **禁止（硬约束）** | ① **不得** include / 调用 **ConfigManager**（`config_*`）；② **不得**使用 **`WiFi.macAddress()`**；③ **不得**含任何 **MQTT / cloud 逻辑**（不 include）；④ **不得**新增 System State 项；⑤ **不得**新增 EventId / 不埋 LogManager；⑥ **不得**接入 Critical Operation；⑦ 头文件名**不得**与现有 26 个重名；⑧ **不得**声明 / 实现 `topic_render()` 或任何模板渲染（已拆至 P0-2）；⑨ **不得**提供 `device_identity_reset()`（v1.2 删除） |
| **风险** | ① MAC 取值路径选错（STA/AP/BT ±1）⇒ 身份漂移；② NVS 首写失败**不可进日志**（无 EventId，见设计 §2.3「可观测性缺口」）⇒ 只能靠串口；③ 头文件名冲突；④ `Preferences` 首次使用需确认 NVS 已由 core 初始化（`nvs_flash_init()` 由 Arduino core 调用） |
| **验证方法** | **编译**：独立 build dir `PLATFORMIO_BUILD_DIR=.pio/build/p0a pio run`（沙箱拦删 `.o/.elf`，禁增量）<br>**静态**：`nm -S` 两份 ELF ⇒ RAM 增量归因到 `s_device_id` 等符号；**`.data/.bss` 符号表 `diff` 逐项一致**（项目铁律：RAM +0/+N 最硬证据）；`size`/`readelf` 看 Flash 增量（**本包预期 +0.8–1.2 KB**；渲染部分在 P0-2）<br>**上板（串口）**：见 §P0-5 的 S-1 ~ S-4<br>**负向检查**：`grep -n 'config_\|WiFi\.macAddress\|mqtt_\|MQTT' src/services/device_identity.*` ⇒ **必须为空** |
